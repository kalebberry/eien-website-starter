# Eien project context

Eien is a minimal Astro website starter. Human design intent governs implementation. AI assistance is optional.

Read only the relevant handbook section:
- [Architecture](context/architecture.md): pages, components, dependencies.
- [Styling](context/styling.md): CSS layers, tokens, Kōshi.
- [Validation](context/validation.md): checks and review.

Inspect actual code before making changes. Do not invent Kōshi APIs; consult its pinned source or upstream documentation. The optional Kōshi Agent Skill is independent. Do not add dependencies, public demos, or new architectural systems without a clear project need. Preserve human review and report checks actually run.
