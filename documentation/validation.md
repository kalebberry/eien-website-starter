# Validation

The vendored Kōshi CSS Git blob matches the upstream v0.2.0 Git blob (a4d06684dca86d54bf7a9e5eed5458124760251a, 17132 bytes). The release download uses CRLF; the repository uses LF.

CI is intended to run architecture checks, token tests, production build and browser smoke tests at five widths across three engines. Results must be inspected before merging. These are starter integration checks, not a full Kōshi regression suite or AI evaluation.

The browser tests inject a small grid into the built homepage rather than shipping demo pages. No public playground is needed.
